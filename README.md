# Digital Brain

## Descrição do Projeto

O **Digital Brain** é uma aplicação desenvolvida para gerenciar informações sobre funcionários, alunos e suas turmas. O objetivo é fornecer uma solução eficiente e escalável, utilizando tecnologias modernas e seguindo as melhores práticas de desenvolvimento de software. A aplicação foi construída com Java e o framework Spring Boot, garantindo um produto de alta qualidade.

## Tecnologias Utilizadas

- **Java 17**: Linguagem de programação principal do projeto.
- **Spring Boot**: Framework para desenvolvimento de aplicações web.
- **JPA (Java Persistence API)**: Para gerenciamento de dados.
- **MySQL**: Sistema de gerenciamento de banco de dados.
- **Flyway**: Ferramenta de migração de banco de dados.
- **Spring Security**: Para autenticação e autorização.
- **JWT (JSON Web Tokens)**: Para autenticação baseada em tokens.
- **Lombok**: Para reduzir o código.
- **ModelMapper**: Para mapeamento de objetos.
- **SpringDoc OpenAPI**: Para geração de documentação da API.
